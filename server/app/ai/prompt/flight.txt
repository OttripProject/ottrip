Analyze the extracted text from a flight ticket and extract the following information in JSON format.

{ocr_text}

## Required Fields
- airline: Airline name (e.g., Korean Air, Asiana Airlines)
- flight_number: Flight number (e.g., KE 123, UA 456)
- departure_airport: Departure airport code (e.g., ICN, NRT)
- arrival_airport: Arrival airport code (e.g., NRT, LAX)
- departure_date: Departure date (YYYY-MM-DD format)
- departure_time: Departure time (HH:MM format)
- arrival_date: Arrival date (YYYY-MM-DD format, if available)
- arrival_time: Arrival time (HH:MM format, if available)
- departure_city: Departure city (e.g., Seoul, Tokyo)
- arrival_city: Arrival city (e.g., Tokyo, Los Angeles)

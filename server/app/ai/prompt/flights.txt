### Rules
1. A "Flight" object represents one direction (outbound or inbound).  
   - If the ticket is round trip, output two Flight objects.  
   - If one way, output one Flight object.  
2. Each "Flight" contains a list of "FlightSegment".  
   - Direct flights → 1 segment.  
   - Connecting flights → multiple segments (order in itinerary order).  
3. If the ticket has price for each direction → put price in each corresponding Flight’s `expense`.  
   If only total price → put in the outbound Flight only.  
4. If a field cannot be found:  
   - String fields → "" (empty string)  
   - Datetime or numeric fields → null  
5. Passenger name and reservation number apply to all flights if given once.  
6. Dates and times must be parsed into ISO 8601 format with timezone if possible.  
   If timezone cannot be determined, still return as ISO (e.g. `"2019-11-15T16:00:00"`).  
7. Use IATA codes for airports if present (e.g. ICN, SFO). If not available, leave `""`.  
8. Use full airline name if possible (e.g. "Korean Air"), otherwise use code.  
9. Output must be **valid JSON**, with no extra commentary.  

### JSON Schema
```json
[
  {
    "reservation_number": "string",
    "passenger_name": "string",
    "plan_id": 123,
    "flight_segments": [
      {
        "order": 1,
        "airline": "string",
        "flight_number": "string",
        "departure_airport": "string",
        "arrival_airport": "string",
        "departure_time": "YYYY-MM-DDTHH:MM:SS",
        "arrival_time": "YYYY-MM-DDTHH:MM:SS",
        "seat_class": "string",
        "seat_number": "string"
      }
    ],
    "expense": {
      "amount": 123456,
      "currency": "KRW",
      "description": "string"
    }
  }
]

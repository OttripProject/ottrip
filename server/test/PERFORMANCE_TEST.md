# API 성능 테스트 가이드

OTTRIP API의 성능을 테스트하는 스크립트입니다.

## 설치

필요한 패키지는 이미 `pyproject.toml`에 포함되어 있습니다:
- `httpx`: 비동기 HTTP 클라이언트

## 사용법

### 기본 사용 (로컬 서버)

```bash
python performance_test.py --base-url http://localhost:8080
```

### 프로덕션 서버 테스트

```bash
python performance_test.py --base-url https://ottrip.onrender.com
```

### 인증이 필요한 엔드포인트 테스트

```bash
python performance_test.py \
  --base-url https://ottrip.onrender.com \
  --auth-token YOUR_ACCESS_TOKEN
```

### 동시 요청 및 요청 수 설정

```bash
python performance_test.py \
  --base-url https://ottrip.onrender.com \
  --concurrent 10 \
  --requests 50
```

### 환경 변수 사용

```bash
export API_BASE_URL=https://ottrip.onrender.com
export AUTH_TOKEN=your_token_here
python performance_test.py
```

## 옵션

- `--base-url`: API 베이스 URL (기본값: `http://localhost:8080`)
- `--auth-token`: 인증 토큰 (Bearer 토큰)
- `--concurrent`: 동시 요청 수 (기본값: 1)
- `--requests`: 엔드포인트당 요청 수 (기본값: 10)
- `--timeout`: 요청 타임아웃 (초, 기본값: 30)
- `--output`: 리포트 출력 파일명 (기본값: `performance_report.json`)

## 테스트되는 엔드포인트

### Public 엔드포인트 (항상 테스트)
- `GET /` - 헬스 체크
- `GET /public/auth/time` - 서버 시간
- `GET /public/auth/keys` - 공개 키

### Private 엔드포인트 (인증 토큰 제공 시)
- `GET /private/users/me` - 사용자 정보
- `GET /private/plans/me` - 내 여행 계획 목록

## 성능 지표 설명

- **평균 응답 시간**: 모든 요청의 평균 응답 시간
- **중간값 응답 시간**: 응답 시간의 중간값 (50번째 백분위수)
- **P95 응답 시간**: 95%의 요청이 이 시간 이내에 완료됨
- **P99 응답 시간**: 99%의 요청이 이 시간 이내에 완료됨

3. 인증 토큰은 환경 변수로 관리하는 것을 권장합니다
4. 타임아웃은 네트워크 상황에 맞게 조정하세요
